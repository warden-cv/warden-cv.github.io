Command-line administration

Warden supports headless first-run provisioning, machine-readable configuration inspection and confirmed recovery commands.

warden setup --username admin --display-name Administrator --password-file /run/secrets/warden-password
warden config show --json
warden service status
warden reset --auth --confirm "WARDEN AUTH"
warden reset --all --confirm "WARDEN ALL"

Stop Warden before a reset. Authentication reset preserves project configuration; full reset preserves the filesystem workspace configured as Warden's file root. Timestamped backups are retained. Omit --confirm to type the phrase interactively.

Use flags, environment variables and the documented HTTP API for repeatable configuration-management workflows; never place passwords directly in command arguments.
