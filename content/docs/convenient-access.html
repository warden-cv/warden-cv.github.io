Convenient browser access

my.warden.cv is a memorable shortcut to your Warden workspace. It avoids having to remember port 7332 or manually type a localhost address and port.

Configure the shortcut

  1. Visit my.warden.cv?config.
  2. Use the defaults for a local Warden instance, or enter the domain or IP address and port of a remote instance.
  3. Select Save, then Open.

From then on, my.warden.cv forwards directly to the saved Warden address.

Local default

http://localhost:7332

The destination is stored in the current browser profile, so configure it separately on another browser or device. Reopen the ?config URL to change it.

Network boundary

The shortcut only navigates the browser; it does not proxy Warden or make the service remotely accessible. Follow Security and the HTTPS deployment guides before exposing a high-authority Warden instance beyond localhost.
